# ОГЛАВЛЕНИЕ ДОКУМЕНТАЦИИ

Проект: эмулятор Intel 8080 + CP/M 2.2 + аппаратный I/O в CODESYS 3.5
(только FBD, генерация схем из PLCopenXML скриптами Python).

**Кратко, самое важное для нового эмулятора:**
1. `SEL(G,IN0,IN1)` = IN1 при G — обернуть в хелпер, не вызывать напрямую.
2. Запись в массив по вычисляемому индексу импортёр ТЕРЯЕТ — писать по
   константным индексам или через блок с входом `Addr`.
3. Тело вызова FB генерируется только при потреблённом выходе (глобально).
4. Значение из `outvar` видно в другой сети только со следующего скана —
   нужны холостые сканы между тактами.
5. Онлайн-сессия стартует с сохранённых значений — нужен явный сброс.
6. Поля декодера живут один скан — латчить их внутри схемы в массивы.
7. Старт системы (ОС/монитор): выключить процессор → PC/SP → включить.
