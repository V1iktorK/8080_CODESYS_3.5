# Документация проекта

Здесь лежит вся документация проекта «Intel 8080 + CP/M 2.2 на FBD в CODESYS 3.5» —
16 документов, написанных по ходу работы, а не после неё. Это не «оформление ради
оформления»: каждый документ отвечает на конкретный вопрос, который возникал при сборке,
и фиксирует то, что иначе пришлось бы искать заново.

## Главное — в шести строках

1. `SEL(G, IN0, IN1)` = `IN1` при `G` — оборачивать в хелпер, не вызывать напрямую.
2. Запись в массив **по вычисляемому индексу импортёр теряет** — писать по константным
   индексам или через блок с входом `Addr`.
3. Тело вызова FB генерируется **только при потреблённом выходе** (глобально).
4. Значение из `outvar` видно в другой сети **только со следующего скана** — нужны
   холостые сканы между тактами.
5. Онлайн-сессия стартует с сохранённых значений — нужен явный сброс состояния.
6. Поля декодера живут один скан — латчить их внутри схемы в массивы.
